# Punto

Calculadora web estática para operaciones diarias. No requiere dependencias ni proceso de build.

## Uso local

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

Después visita <http://localhost:8000>.

Incluye operaciones básicas, porcentajes, cambio de signo, borrado, historial de operaciones y soporte de teclado.
